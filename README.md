# Raspagem de Dados de Produtos (PT)
Desenvolvimento de pipeline de web scraping para coleta, padronização e análise de dados de produtos em múltiplos e-commerces, visando a identificação automatizada das melhores ofertas do mercado.

# Extracción de Datos de Productos (ES)

Desarrollo de un pipeline de web scraping para la recolección, estandarización y análisis de datos de productos en múltiples e-commerce, con el objetivo de identificar de forma automatizada las mejores ofertas del mercado.


# Product Data Scraping (EN)

Development of a web scraping pipeline for collecting, standardizing, and analyzing product data across multiple e-commerce platforms, aimed at the automated identification of the best market deals.
